## What is Anilife?

Anilife is a community-built anime streaming project. Instead of one shitty framework that would run on any device but badly, we spend our time building **truly native clients for each platform**,

Watch on the couch, while on the goon, at your desk, or in a browser tab.

  ## Repositories

| Platform | Repo | Stack | Status |
| :-- | :-- | :-- | :-- |
| **Android, Android TV, Fire TV** | [`android-and-tv`](https://github.com/anilifecommunity/android-and-tv) | Kotlin + Jetpack Compose | Active |
| **iOS** | [`ios`](https://github.com/anilifecommunity/ios) | Swift | Active |

## Why native?

- **Fast.** Each client is written for its own platform, not wrapped in a webview and prayed for the best.
- **Open.** Our repos are permissively licensed (**MIT-0**), so you can read, learn from, fork and remix.
- **Community-first.** Built by fans, for fans.

## Join the crew
